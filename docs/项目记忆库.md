## 环境与运行

### 本机无 PostgreSQL 二进制时的游戏启动路径

- 状态：本机未安装 `postgresql@17`，`initdb`、`psql`、`pg_ctl` 不在 PATH，`/opt/homebrew/opt/postgresql@17/bin` 不存在，因此 `pnpm db:start` / `pnpm db:stop` 不可用。
- 替代路径（已验证可持久化运行）：
  1. `open -a Docker`，等待 daemon 就绪（约 60s）
  2. `docker compose up -d db`：容器 `voxel-postgres`，宿主端口 `55432`，镜像 `postgres:17-alpine`（本地已有缓存）
  3. `pnpm db:generate`
  4. `pnpm db:migrate`
  5. `pnpm dev`：前端 `127.0.0.1:5173`，后端 `127.0.0.1:2567`
- 校验：`curl 127.0.0.1:2567/health` 返回 `persistence=postgresql` 表示已连库（内存模式会不同）。不要通过清空 `DATABASE_URL` 退回内存模式来绕过启动失败。

### Docker Compose 拉取失败时复用本地 PostgreSQL 镜像

项目依赖 `postgres:17-alpine`，Docker Hub 拉取超时时，可用本机已有的 `postgres:17.5-alpine` 打标签复用：`docker tag postgres:17.5-alpine postgres:17-alpine`，再 `docker compose up -d db`。
